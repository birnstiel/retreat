# Introduction to Interferometric Imaging

*Lecture & Hands-on session — Thursday, April 30, 14:00*

&nbsp;

### Overview

We will do exercises on CARTA using the exoALMA emission line FITS files. If time permits, we will also do an exercise on simulating observations with CASA.

&nbsp;

### Preparation

1. Install CARTA using [https://cartavis.org/#download](https://cartavis.org/#download). Go to the `Stand-alone application` tab, and download the software for Mac or Linux.

2. Download only one FITS file of your favourite emission line in your favourite exoALMA disk: [https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/CFHWNH](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/CFHWNH). If you have difficulty picking, we recommend picking HD 34282, which is a famous vortex candidate. Please download any file that ends with `fiducial.image.fits`.

3. Install the ALMA pipeline of CASA from [https://casa.nrao.edu/casa_obtaining.shtml](https://casa.nrao.edu/casa_obtaining.shtml). Along with it, download [this FITS file](model_disk_tutorial.fits).
