### Instructions

Installing pyFLD:

1. Navigate to [https://github.com/alexziab/pyFLD](https://github.com/alexziab/pyFLD) and clone the repository:

   ```
   git clone git@github.com:alexziab/pyFLD.git
   ```

2. Enter the pyFLD directory:

   ```
   cd pyFLD
   ```

3. Run the following from your terminal — this should also install any dependencies (e.g., astropy):

   ```
   pip install .
   ```

We'll mostly work with the examples in the directory pyFLD/examples/hands-on
